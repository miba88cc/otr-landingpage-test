# OTR GO®

Experimentelle, responsive Portfolio-Testwebsite von OTR-OnTouR. Eigenständige Umsetzung, inspiriert vom Editorial- und Immersive-Stil der vom Auftraggeber angegebenen Referenz.

**Live-Vorschau (nach Pages-Deployment):** https://www.otr-ontour.com/otr-go/

**Datei:** `index.html` – enthält HTML, CSS und JavaScript ohne Buildtools.

**Medien:** Originaldateien von https://www.otr-ontour.com/ werden direkt eingebunden; kein Duplizieren. Beim Umbenennen eines Assets muss der zugehörige Link im HTML angepasst werden.

**Features:** Showreel-Hero, Filter für Video/Foto, Portfolio-Lightbox, interaktives Disziplinen-Orbit, Fullscreen-Menü, Scroll-Animationen, mobil optimierte Ansichten, Reduced-Motion-Unterstützung, Kontaktlinks. Die Testseite enthält `noindex,nofollow`.

**Sicherheit:** Die produktive OTR-Startseite wird nicht geändert. Die zusätzliche Vorschau liegt isoliert unter `/otr-go/`.
